# FitLog 🏋️

**FitLog** is a dark, responsive workout-library web application built with Next.js. It lets users explore exercises, open detailed workout pages, add workouts to **Today's Plan**, save workouts for later, and manage their personal workout list from the **My Plan** page.

## 🔗 Project Overview

FitLog is designed as a simple, no-nonsense gym companion:

- Browse a library of workouts
- View complete workout details
- Add exercises to today's plan
- Save exercises for later
- Track workout time and calories
- Sort planned/saved workouts by duration, calories, or rating

The interface follows a dark fitness-focused design with responsive layouts for mobile, tablet, and desktop.

## 🛠️ Technologies Used

- **Next.js** — App Router and dynamic routing
- **React** — Component-based UI
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling
- **DaisyUI** — UI utilities and components
- **React Toastify** — Toast notifications
- **Lucide React** — UI icons
- **React Icons** — Additional icons
- **Next/Image** — Optimized image rendering
- **External FitLog API** — Workout data source

## ✨ Key Features

**1.Responsive Library & Sorting:** Adaptable grid of detailed workout cards, with sorting by duration, calories, and rating.

**2.Dynamic Workout Details:** Dedicated pages featuring step-by-step instructions and quick actions to add to "Today's Plan" or "Save".

**3.Plan Management:** Separate tabs to organize Today's Plan and Saved workouts, synced with live navbar counters.

**4.Live Metrics & Notifications:** Real-time tracking of total time, calories, and exercises, plus instant toast feedback for user actions.

**5.Optimized UI/UX:** Mobile-friendly navigation, skeleton loaders, friendly empty states, and a custom 404 error page.
